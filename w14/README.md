# W14 — Agentic Routing with LLMs & Transformers

Fusemachines AI Fellowship 2026 submission for the ShopAssist AI support-routing
assignment: fine-tuning and comparing an encoder-only classifier (Approach 1) against
a decoder-only SLM (Approach 2) for routing customer messages to one of 11 specialized
support agents.

## Repo Structure

```
w14/
├── model_weights/          Saved model checkpoints from training
├── public/                 Generated plots (loss curves, confusion matrices, comparisons)
├── task/                   Assignment brief + the unfilled starter notebook
└── support_routing.ipynb   FINAL notebook — this is the one to open/grade
```

### `model_weights/`
Trained weights from both approaches, saved by the `Trainer` / `SFTTrainer` during
the notebook run.
- `enc_results/` — checkpoints for the fine-tuned encoder (Approach 1, DistilBERT).
- `Qwen2.5-0.5B-Instruct/` — LoRA adapter weights for the fine-tuned decoder
  (Approach 2, Qwen2.5-0.5B-Instruct).
- `README (1).md` — auto-generated model card written by the Trainer/Hub tooling
  when the checkpoint was saved (not authored by hand).

### `public/`
All required plots, generated by the notebook and saved out as PNGs so they can be
viewed without re-running the code.
- `loss_curve.png` — Approach 1 (encoder) train/validation loss curve.
- `confusion_matrix_heatmap.png` — Approach 1 (encoder) confusion matrix.
- `qwen_loss_curve.png` — Approach 2 (decoder) train/validation loss curve.
- `qwen_confusion_matrix_heatmap.png` — Approach 2 (decoder) confusion matrix.
- `Comparision bar chart.png` — first-pass comparison chart (linear 0–1 axis; both
  models score ~0.999 so the bars look identical here).
- `detailed_comparison_bar_chart.png` — revised comparison chart: left panel zooms
  the y-axis into the ~0.99–1.0 band with 4-decimal labels so the fractional
  difference between models is actually visible; right panel plots latency and
  peak GPU memory on a log scale.

### `task/`
Reference material for the assignment, not part of the submission.
- `W14_Assignment.pdf` — the assignment brief: task description, the 11 agents/intents,
  dataset details, required metrics/plots, and submission requirements.
- `sample_support_routing.ipynb` — the original starter notebook with `# TODO` markers,
  before it was filled in.

### `support_routing.ipynb`
The final, completed notebook — **this is the file to submit and review**. Runs
top-to-bottom without errors and contains:
- Approach 1: DistilBERT fine-tuned as an 11-class `[CLS]`-token classifier.
- Approach 2: Qwen2.5-0.5B-Instruct fine-tuned with LoRA to generate the agent name
  as a single token.
- Required plots (loss curves, confusion matrices, comparison chart), the comparison
  table, the recommendation (addressed to the ShopAssist AI engineering lead), and
  the reflection answers.
